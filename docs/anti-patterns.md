# Anti-patterns

## Prompt as Architecture

A large prompt is not governance. Rules that affect real decisions need explicit ownership and review.

## Retrieval as Truth

Search can recover context. It cannot decide by itself what is current, authoritative or permitted.

## Automation Before Simplification

Automating an unstable process scales its exceptions and errors.

## Chatbot Theater

A conversational interface without state, authority or write-back remains an interface rather than an operational system.

## Completion Without Evidence

Model output is not proof that an action occurred or produced the intended result.

## No Write-back

If execution does not update durable state, the next session restarts from incomplete context.

## Unbounded Agency

No agent should infer permission from capability. External side effects require explicit scope, authorization and a failure path.
