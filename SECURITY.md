# Security Policy

This repository should contain only the allowlisted public reference documents.

Do not submit secrets, credentials, private prompts, client data, production code or implementation details in issues, pull requests or discussions.

If you find sensitive information or an artifact outside the declared public boundary, do not open a public issue. Report it through https://fstech.digital/contato with the repository path and a short description. Do not include the sensitive value itself.

Unsafe examples that encourage unapproved external actions may also be reported privately through the same channel.
